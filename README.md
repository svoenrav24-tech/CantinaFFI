# CantinaFFI — Laboratorul 1 Java
Toate clasele sunt în pachetul `cantinaffi`.

- `CantinaA1`: meniu și cost.
- `CalificativA2`: validare notă.
- `Produs` și `ProduseA3`: încapsulare și obiecte.
- `BonFiscalB1`: reducere bursier 15%, apoi TVA 20%.
- `MeniuInteractvB2`: comandă interactivă, reducere 15% dacă subtotalul depășește 100 lei.
- `VerificareProdusB3`: căutare cu `equals`, disponibilitate și cost.
- `RestBancnoteC1`: operatorii `/` și `%`, fără `if` și fără cicluri.
- `BonDetaliatC2`: cantități și subtotaluri per produs.
- `CodScurtC3`: exemplu `ZEA24`.

## IntelliJ IDEA
Creează proiectul `CantinaFFI`, apoi pachetul `cantinaffi` în `src`. Copiază fișierele Java și rulează separat fiecare clasă care conține `main`.
Exemplu B1: introdu `2`, apoi `2`, apoi `true`. Totalul așteptat este 93.84 lei.
Exemplu B2/C2: introdu produsul `2` cu 1 porție, apoi produsul `2` cu 1 porție, apoi produsul `3` cu 1 porție și la final `0`.
